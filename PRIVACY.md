# Privacy

MB X7 Control operates locally on the Mac and does not collect analytics,
telemetry, crash reports, advertising identifiers, contact information, or
usage data. The application does not include a network client or transmit data
to the project maintainer or any third party.

The application communicates locally with a connected Creative Sound Blaster
X7 over USB and with macOS audio services. It can enumerate local audio-device
names and identifiers so the user can choose playback and recording devices.
It does not record, inspect, store, or transmit microphone or audio content.

Preferences such as the selected X7 settings, Mixer mute choices, preferred
macOS audio-device identifiers, and Open at Login state are stored locally by
macOS on the user's Mac. Removing the application does not automatically
remove these preferences.

The optional donation provider and GitHub are separate services governed by
their own privacy policies. MB X7 Control does not embed either service in the
application.

The project is maintained by [alcatron](https://github.com/alcatron) at
[`alcatron/mb-x7-control`](https://github.com/alcatron/mb-x7-control).
