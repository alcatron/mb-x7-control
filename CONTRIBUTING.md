# Contributing

Contributions that improve compatibility, reliability, accessibility,
documentation or the native macOS experience are welcome.

The project home is
[`alcatron/mb-x7-control`](https://github.com/alcatron/mb-x7-control), maintained
by [alcatron](https://github.com/alcatron).

By submitting a contribution, you confirm that:

- you have the right to submit it;
- it is your original work or is accompanied by compatible licensing and
  attribution information; and
- you license the contribution under the project's current licence in
  [`LICENSE`](LICENSE).

Do not submit Creative binaries, private frameworks, decompiled source code,
copyrighted artwork, confidential material, or code that requires those items
at runtime. Protocol observations and independently written interoperability
implementations are welcome when their origin is documented.

Please describe the X7 hardware configuration and macOS version used for any
hardware-facing change. Changes that write new or unverified values to the X7
should include evidence, safety considerations and a reversible test plan.
